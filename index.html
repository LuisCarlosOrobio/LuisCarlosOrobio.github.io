    visual-web-ai

    ReScript · WGSL · WebGPU

    A neural network compiler and runtime that runs entirely in the browser. ReScript generates optimized WGSL compute shaders, WebGPU executes them on the GPU, and autograd handles backpropagation. No server.

  • 2023–

    Andropia

    Python · Three.js · VRM · WebGL

    A deterministic sandbox for embodied intelligence: language models inhabiting bodies in a shared 3D world, perceiving it, moving through it, and talking to each other. Beings are told what is around them in words rather than coordinates, and act by writing tags inline in their speech. A seed plus the intent log replays any run exactly — replay never calls a model, so a run reproduces whatever the temperature was and whether or not the endpoint still exists.

    demo video code

  • 2024

    Symbolic tensor calculus for general relativity

    OCaml · js_of_ocaml · Three.js

    Give it a metric tensor and it derives the Christoffel symbols, Riemann and Ricci tensors, Einstein tensor, and geodesics by exact symbolic differentiation — nothing hardcoded, every algebraic step traceable. Compiles to JavaScript, so the whole engine runs in the browser alongside a Three.js embedding diagram. Ships with Morris-Thorne, Ellis, and zero-tidal-force wormhole metrics.

    Screenwriting by probabilistic graph

    Fine-tuning · Probabilistic graphical models

    A language model fine-tuned on a hundred art films that generates scripts by sampling scene graphs, rather than continuing a sequence left to right.
